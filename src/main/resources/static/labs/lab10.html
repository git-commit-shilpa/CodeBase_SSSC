Lab 10

The Purpose

The lab will show how the login page can be exploited

Pre-steps

Open the login page. Click here to open the login page or navigate to http://localhost:8888/login.

Steps

In the /Web/WebController.java file, find the login method that maps the POST /login URL to code. Place a breakpoint on the method that calls this.loginController.Login(...).

Restart the application with debugging turned on.

Now, attempt to login and step through to see what happens.

Note that The LoginController.Login calls MemberModel.CheckLogin, which then calls MemberDataAccess.getMemberByCredentials.



In MemberDataAccess.java in the getMemberByCredentials method, place a breakpoint on the line after the String sql is defined and assigned. Attempt to login and see what the value of the String sql is.

  • "select memberid, username, fullname from member where username = 'rflorin' AND password = 'test'"
  1. How can you see the full value of the String sql?
  2. Can you think of a string to type in for the username or password that will cause issues here?
