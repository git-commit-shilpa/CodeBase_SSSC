Lab 2

The Purpose

The lab will show off the Reflected Cross Site Scripting (XSS) attack.

Pre-steps

Login to the site using the login page. Click here to open the login page or navigate to http://localhost:8888/login. Use the appropriate credentials to login.

Next, click the "To Search Page" link to open the page.

In the URL, add any text to the "query" querystring value. For example, /search?query=Test. Then click enter to open that page. Notice the value for query appears next to the "showing search results for:" text.

Steps

Attempt the following Reflected XSS attacks:

  • <script>alert("XSS");</script>
  • <img src="x" onerror="window.location='http://www.google.com'">
  • <div style="background:red;">TEST</div>

Notice that the page will run whatever script you enter in. Why?

Why?

In VSCode, open the src/main/java/com/securecode/Web/WebController.java file.

Navigate down to line 145. This is where the /search page is handled. In the parameters of the method, there are the following:

  1. HttpServletResponse response
  2. @CookieValue(value="Session") String sessionid
  3. @RequestParam String query

The value of the "query" request parameters is mapped to the "query" parameter.

Now, scroll down to the next few lines. Notice we take the value of query and "inject" it into the returned html.
