Lab 13

The Purpose

The lab will show how the SQL Injection can be used to change the data in the database.

Pre-steps

Open the login page or the edit page.

Steps

In SQL, you can end the current command using a semicolon. Meaning, you can send multiple commands to the database.

To delete a table from a database, you can run the following command:

  • DROP TABLE tablename;

To insert a record into a table, you can run the following command:

  • INSERT INTO member (memberid, username, password, fullname, role) VALUES (10, 'student', 'test', 'Sara Tudent', 'admin');
  • Can you use SQL Injection to DROP the member table? Note: You can restart the server to re-create the database.
  • Can you use SQL Injection to INSERT a new user for yourself, then use it to login?
