Lab 3

The Purpose

The lab will show off the Stored Cross Site Scripting (XSS) attack.

Pre-steps

Open the message page. Click here to open the it or navigate to http://localhost:8888/.

Add or edit one of the existing messages.

Open the message page in another browser window or even another browser. The new message is stored in the h2 database.

Steps

Attempt the following Stored XSS attacks:

  • <img src="x" onerror="alert(`XSS`)">
  • <button onmouseover=alert("XSS")>click me!</button>

Now, try the following.

  • <img src="x" onerror="window.location=`http://www.google.com`">

The page is redirected to another website. Reopen the message page. What happens?

To reset the data for the site, stop the server, then restart. The default data will be reloaded.
