These instructions assume you use VSCode.  
1. If you dont already have it installed - install VSCode
2. Navigate to: https://code.visualstudio.com/docs/languages/java
   a. Click the "Install the Coding Pack for Java"  to download.
   b. Follow the prompts to install the Coding Pack
   c. On the same page, scroll down and click "Install the Extension Pack for Java"
   d. This will open VSCode - Follow the prompts to install (This may already be installed)
3. Open the SecureCode-Lab directory in VSCode
4. Open the securecode.java file and Press F5 to run the application
5. In your browser, navigate to http://localhost:8888/
   a. The message board should show.  This can be used to practice Stored XSS and SQL Injection attacks.
6. In your browser, navigate to http://localhost:8888/search?query=999
   a. The search page should show.  This can be used to practice Reflected XSS Attacks.
7. If steps 5 and 6 did not work, please contact rflorin@georgiasouthern.edu about fixing this issue before class.
