Lab 4

The Purpose

Learn some differences in how these attacks work, and learn some "primitive" protections

Pre-steps

Attempt the following attacks using a Reflected XSS and Stored XSS.

  • <script>alert("XSS");</script>
  • <img src="x" onerror="alert(`XSS`)">
  • <img src="x" onerror="alert('XSS')">

Try this!

Part 1.

Attempt a Reflected XSS and a Stored XSS using the following:

  • <script>alert("XSS");</script>

Why does it act differently?

Part 2.

Try running the following two as a Stored XSS attack:

  • <img src="x" onerror="alert(`XSS`)">
  • <img src="x" onerror="alert('XSS')">

Notice the difference in them. One uses backticks (`) and one uses single quotes (').

Why?

Take some time. Investigate why they act differently. We will discuss more as a class. Here are some things to try:

  • Open up the developer tools of the browser. Are there differences in how they are rendered in Reflected vs Stored XSS?
  • Open up the code for how these pages work. Are there differences in how Reflected vs Stored works?
  • There may be hints to certain issues in the Client-side console logs. In the developer tools, open the Console tab. Are there errors listed?
  • There may be hints to certain issues in the Service-side debug logs. In VSCode, or the terminal, are there any errors listed?
