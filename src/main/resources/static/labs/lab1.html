Lab 1

The Purpose

The lab will show off the application and how to navigate around.

The Message Page

The message page: Click here to open the message page or navigate to http://localhost:8888.

From the message page, there are three activities that can be done. First, you can read the messages. Second, you can click on a message to see more information on the message. Third, you can click the + button to add a new message. You do not need to be logged in to the application to see, edit, or add a message.

When the page loads, each of the messages will be shown to the user.

To Edit a message, click on the message you want to edit. After the modal loads, click the Edit button to edit the message.

To Add a message, click the + button. This will open a modal to add a message.

Data Fields

When updating the Author Id, the value selected must be an integer that matches to an authorid in the database.

When updating the Message, any values may be entered in.

The Login Page

The login page: Click here to open the login page or navigate to http://localhost:8888/login.

To login, you must enter appropriate credentials. You can test this out by using the credentials listed below

The Login Splash Page

Once logged in, there are two options. First, you can navigate to the search page. Second, you can navigate to the Verify Cookie page.

Verify Cookie Page

The Verify Cookie page will display the current user's Session Id from the cookie and the matching userId for that cookie.

Search Page

The Search Page is an example for Reflected XSS. The page is used to display text from the URL into the search results section of the page.
