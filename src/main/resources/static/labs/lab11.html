Lab 11

The Purpose

The lab will show how the edit message can be exploited

Pre-steps

Open the message page.

Steps

In the src/main/java/com/securecode/restService/MessageAPIController.java file, find the POST mapping for /api/message/{id}. Put a breakpoint on line 55 where this.messageController.updateMessage is called.

Restart the application with debugging turned on.

Now, attempt to edit a message and step through to see what happens.

Notice MessageController.updateMessage calls MessageModel.UpdateMessage, which calls MessageDataAccess.updateMessage.



In MessageDataAccess.java in the updateMessage method, place a breakpoint on the line after the String sql is defined and assigned. Attempt to edit a message and see what the value of the String sql is.

  • "update message set authorid = 1, message = 'test123123' where messageid = 1"
  1. How can you see the full value of the String sql?
  2. Can you think of a string to type in for the message that will cause issues here?
